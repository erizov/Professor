## Где применяется

- отслеживание версий датасетов в ML-пайплайнах с DVC или Git LFS;

- контроль изменений схемы данных и метаданных;
- версионирование моделей машинного обучения;

## Пример

Пример работы model versioning:

1. Инициализация репозитория: создание DVC репозитория для отслеживания версий датасета
2. Добавление данных: загрузка датасета train.csv (10000 строк, версия v1.0) в DVC storage
3. Коммит версии: сохранение метаданных версии в Git с хешем данных и метаданными (размер, схема, дата)
4. Изменение данных: обновление датасета до v1.1 (12000 строк, добавлено поле 'category')
5. Сравнение версий: анализ различий между v1.0 и v1.1 (изменения в размере, схеме, распределении)
