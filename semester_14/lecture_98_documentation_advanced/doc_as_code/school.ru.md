# Doc As Code

## Простое объяснение

Doc As Code — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.


## Где применяется

- применение doc as code для решения конкретных задач в области doc;
- использование doc as code в production-системах для code;
- интеграция doc as code в data pipelines для автоматизации процессов;
