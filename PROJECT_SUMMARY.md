## 🚀 Usage Examples

### Run an Algorithm
```bash
python runner.py --semester 5 --lecture 25 --algorithm transformer
```

### Get Recommendation
```python
from framework.constraint_selector import AlgorithmSelector, Constraints

constraints = Constraints(
    memory=ResourceLevel.LOW,
    is_edge_device=True
)
rec = AlgorithmSelector.select_sorting_algorithm(constraints)
```

### Benchmark Performance
```python
from framework.performance_timer import benchmark

@benchmark(dataset_sizes=[100, 1000, 10000])
def my_algorithm(data):
    return sorted(data)
```

### Start Web UI
```bash
python web_interface/app.py
# Open http://localhost:5000
```
