# Student Sandbox Guide

## How to Access and Use the Sandbox

This guide explains the steps for a student to access and run algorithms in the sandbox.

---

## Step-by-Step Instructions

### Step 1: Login
1. Open your web browser and navigate to: `http://localhost:5000/login`
2. Enter your **username** and **password** (provided by your professor)
3. Click **Login**

**Example credentials:**
- Username: `student`
- Password: `student123`

---

### Step 2: Navigate to Sandbox
After logging in, you have several options to access the sandbox:

#### Option A: From Main Page
1. You will be redirected to the main page (`http://localhost:5000/`)
2. Look for the **"Algorithm Sandbox"** card in the quick links section
3. Click on the card to go to the sandbox page

#### Option B: From Navigation Menu
1. On any page, look at the top navigation menu
2. Click on **"Sandbox"** link
3. You will be taken to: `http://localhost:5000/sandbox`

#### Option C: Direct URL
- Simply navigate to: `http://localhost:5000/sandbox`

---

### Step 3: Create a Sandbox
1. On the sandbox page, you will see:
   - **Algorithm** dropdown (select an algorithm)
   - **Language** dropdown (Python or Java)
   - **Create Sandbox** button

2. **Select an algorithm:**
   - Click the **Algorithm** dropdown
   - Choose an algorithm you want to experiment with (e.g., `bubble_sort`)

3. **Select a language:**
   - Choose **Python** or **Java** from the Language dropdown

4. **Create the sandbox:**
   - Click the **Create Sandbox** button
   - A copy of the original algorithm will be created for you
   - The code will appear in the code editor

---

### Step 4: Edit the Code
1. The code editor will display the algorithm code
2. You can now **modify the code** as you wish
3. Make your changes directly in the editor

---

### Step 5: Save Your Changes (Optional)
1. Click the **Save** button to save your current version
2. Each save creates a new version
3. You can view all your saved versions later

---

### Step 6: Run Your Code
1. After editing (or without editing), click the **Run** button
2. The output will appear in the **Output** section below the editor
3. You will see:
   - **stdout**: Standard output from your code
   - **stderr**: Any errors or warnings
   - **Execution time**: How long the code took to run

---

### Step 7: View Your Sandboxes
1. Click the **My Sandboxes** button
2. A list of all your sandboxes will appear
3. Click on any sandbox to load it into the editor
4. You can switch between different sandboxes easily

---

## Troubleshooting

### "Access denied" message
- Make sure you are logged in with a **student**, **professor**, or **admin** account
- If you see "Access denied", contact your professor

### Code doesn't run
- Check the **Output** section for error messages
- Make sure your code syntax is correct
- For Python: Check for indentation errors
- For Java: Check for compilation errors

### Can't find an algorithm
- Make sure the algorithm exists in the course
- Try using the **Algorithm Executor** page to browse all available algorithms

## Example Workflow

1. **Login** → `http://localhost:5000/login`
2. **Go to Sandbox** → Click "Sandbox" in navigation or go to `http://localhost:5000/sandbox`
3. **Select Algorithm** → Choose `bubble_sort` from dropdown
4. **Select Language** → Choose `Python`
5. **Create Sandbox** → Click "Create Sandbox" button
6. **Edit Code** → Modify the bubble sort implementation
7. **Run Code** → Click "Run" to test your changes
8. **Save** → Click "Save" to save your version
9. **View Results** → Check the output section for results
