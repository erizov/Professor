# Teaching Resources
## Instructor Guide for Algorithms Course

**Purpose**: Comprehensive resources for educators teaching the 16-semester algorithms course.

---

## Lecture Slides

### Template Structure

Each lecture should include:
1. **Title Slide**: Lecture number, title, learning objectives
2. **Introduction**: Context and motivation
3. **Core Concepts**: Main algorithm/pattern explanation
4. **Examples**: Worked examples with step-by-step breakdown
5. **Visualizations**: Diagrams, animations, code traces
6. **Practice**: In-class exercises
7. **Summary**: Key takeaways, complexity analysis
8. **Next Steps**: Homework, readings, preparation

### Slide Design Guidelines

- **Visual**: Use diagrams, code snippets, animations
- **Concise**: 1 concept per slide, max 7 bullet points
- **Interactive**: Include questions, polls, exercises
- **Consistent**: Use same template, fonts, colors

## Teaching Notes

### For Each Algorithm

**Preparation (30 minutes before class):**
- Review algorithm implementation
- Prepare worked examples
- Anticipate student questions
- Prepare common mistakes discussion

**During Class (60-90 minutes):**
- **Introduction (10 min)**: Context, motivation, use cases
- **Explanation (20 min)**: Algorithm walkthrough, complexity
- **Example (15 min)**: Worked example on board/screen
- **Practice (20 min)**: In-class exercises, pair programming
- **Discussion (10 min)**: Q&A, common mistakes, variations
- **Summary (5 min)**: Key points, homework, next steps

## Activity Guides

### In-Class Activities

**1. Algorithm Tracing (15 minutes)**
- Give students input data
- Have them trace algorithm execution step-by-step
- Compare with correct trace
- Discuss differences

**2. Pair Programming (20 minutes)**
- Pair students (driver/navigator)
- Implement algorithm together
- Rotate roles every 10 minutes
- Review code together

**3. Code Review (15 minutes)**
- Provide buggy implementation
- Students find and fix bugs
- Discuss solutions
- Review best practices

**4. Performance Analysis (20 minutes)**
- Compare two algorithms
- Measure performance
- Analyze complexity
- Discuss trade-offs

**5. Design Challenge (30 minutes)**
- Present real-world problem
- Students design solution
- Implement algorithm
- Present and discuss

## Assessment Tools

### Quizzes

**Format**: 10-15 questions, 30 minutes
- Multiple choice (40%)
- Short answer (30%)
- Code analysis (30%)

**Topics**:
- Algorithm understanding
- Complexity analysis
- Implementation details
- Use cases

### Projects

**Format**: 2-3 week project
- Implement algorithm
- Apply to real problem
- Write documentation
- Present solution

**Grading Rubric**:
- Correctness (30%)
- Efficiency (20%)
- Code Quality (20%)
- Documentation (15%)
- Presentation (15%)
