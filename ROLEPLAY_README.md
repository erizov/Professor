# Симуляция диалога и анализ качества общения

Система для создания ролевой симуляции диалога между специалистом (администратором гостиницы) и недовольным клиентом, с последующим анализом качества общения и выработкой рекомендаций.

## Файлы

- `roleplay_quality_analysis.py` - версия для Google Colab
- `roleplay_quality_analysis_local.py` - версия для локального запуска

## Установка и настройка

### Для Google Colab

1. Откройте файл `roleplay_quality_analysis.py` в Colab
2. Добавьте секрет с API ключом OpenAI:
   - Меню → Секреты → Добавить секрет
   - Имя: `OPENAI_API_KEY`
   - Значение: ваш API ключ OpenAI
3. Запустите ячейки

### Для локального запуска

1. Установите зависимости:
```bash
pip install openai
```

2. Установите переменную окружения:
```bash
# Windows (PowerShell)
$env:OPENAI_API_KEY="your-key-here"

# Linux/Mac
export OPENAI_API_KEY="your-key-here"
```

3. Запустите скрипт:
```bash
python roleplay_quality_analysis_local.py
```

## Что делает скрипт

### Шаг 1: Симуляция диалога
Создает реалистичный диалог между администратором гостиницы и недовольным клиентом:
- Клиент обнаружил проблемы в номере (грязь, не работает кондиционер, шум)
- Администратор пытается решить проблему профессионально
- Диалог включает 8-12 реплик с эмоциями и профессиональными ответами

### Шаг 2: Анализ качества
Проводит детальный анализ работы администратора по критериям:
1. **Эмпатия и понимание** - проявляет ли понимание проблемы клиента
2. **Профессионализм** - сохраняет ли спокойствие и профессионализм
3. **Решение проблемы** - предлагает ли конкретные решения
4. **Коммуникация** - ясно ли формулирует предложения
5. **Результат** - удалось ли разрешить ситуацию

Для каждого критерия выставляется оценка (1-10) и дается детальный анализ.

### Шаг 3: Детальные рекомендации
Генерирует практические рекомендации для улучшения работы:
- Конкретные фразы и формулировки
- Пошаговый алгоритм действий
- Что избегать (типичные ошибки)
- Примеры идеальных ответов
- Дополнительные рекомендации по обучению

## Структура промптов

### Промпт для симуляции диалога
- **Роль**: Опытный сценарист
- **Цель**: Создать реалистичный диалог
- **Инструкция**: 
  - Ситуация с конкретными проблемами
  - Структура диалога (8-12 реплик)
  - Формат вывода (КЛИЕНТ/АДМИНИСТРАТОР)

### Промпт для анализа качества
- **Роль**: Эксперт по качеству обслуживания
- **Цель**: Провести детальный анализ
- **Инструкция**:
  - 5 критериев оценки
  - Оценка по шкале 1-10
  - Выявление сильных и слабых сторон
  - Конкретные рекомендации

### Промпт для рекомендаций
- **Роль**: Тренер по работе с клиентами
- **Цель**: Дать практические рекомендации
- **Инструкция**:
  - Конкретные фразы и формулировки
  - Пошаговый алгоритм
  - Примеры правильных ответов
  - Что избегать

## Выходные данные

Скрипт выводит:
1. Полный диалог между клиентом и администратором
2. Детальный анализ качества общения с оценками
3. Практические рекомендации для улучшения

Результаты также сохраняются в файл `quality_analysis.txt` (локальная версия).

## Пример использования

```python
# В Colab
from roleplay_quality_analysis import main
results = main()

# Или локально
python roleplay_quality_analysis_local.py
```

## Настройка параметров

Вы можете изменить:
- `temperature` - креативность ответов (0.3-0.7)
- `max_tokens` - максимальная длина ответа
- Модель (`gpt-4` или `gpt-3.5-turbo`)

## Требования

- Python 3.7+
- OpenAI API ключ
- Библиотека `openai`
- Для Colab: `google-colab` (уже установлена)

## Примечания

- Скрипт использует GPT-4 для более качественных результатов
- Можно использовать GPT-3.5-turbo для экономии (измените `model="gpt-3.5-turbo"`)
- Все промпты оптимизированы для русского языка
- Результаты сохраняются для последующего анализа
