# Zk Snarks

## Простое объяснение

ZK-SNARKs (Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge) — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.


## Где применяется

- применение zk snarks для решения конкретных задач в области zk;
- использование zk snarks в production-системах для snarks;
- интеграция zk snarks в data pipelines для автоматизации процессов;
