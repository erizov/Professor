# Breadth-First Поиск

## Простое объяснение

Breadth-First Поиск — это алгоритм поиска определённого элемента в структуре данных. 
Алгоритм проверяет элементы по определённой стратегии, пока не найдёт нужный или не убедится, 
что его нет.

## Где применяется

- поиск ученика в списке класса;
- поиск нужного файла в папке;
- поиск слова в текстовом документе;
- поиск контакта в списке телефонных номеров;
