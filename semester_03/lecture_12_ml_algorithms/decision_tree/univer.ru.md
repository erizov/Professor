# Дерево решений

**Алгоритм:** Decision Tree  
**Дисциплина:** Machine Learning / AI

## Определение алгоритма

Дерево решений — это алгоритм машинного обучения для классификации и регрессии,
который строит древовидную модель решений. Алгоритм рекурсивно разделяет данные на основе признаков,
максимизируя информационный выигрыш или уменьшая неопределённость (энтропию, Gini impurity),
создавая правила вида "если признак X имеет значение Y, то...".

## Техническое описание

### Что делает алгоритм

Дерево решений — это алгоритм машинного обучения, который строит дерево решений
для классификации или регрессии. Алгоритм рекурсивно разделяет данные на основе признаков, максимизируя
информационный выигрыш (information gain) или уменьшая неопределённость (Gini impurity, entropy).

**Основные этапы:**
1. Выбор лучшего признака для разбиения (максимизация information gain)
2. Разделение данных по выбранному признаку
3. Рекурсивное построение поддеревьев для каждой части
4. Остановка при достижении критерия (чистота узла, глубина, минимальное число образцов)
5. Присвоение метки класса листовым узлам

**Ключевые структуры данных:**
- Бинарное дерево для представления решений
- Таблицы данных для хранения обучающих примеров
- Метрики качества разбиения (Gini, entropy, information gain)

**Временная сложность:** O(n × m × log n), где n — число образцов, m — число признаков

**Пространственная сложность:** O(n × m) для хранения данных

**Сильные стороны:**
- Интерпретируемость (можно визуализировать правила)
- Не требует нормализации данных
- Работает с категориальными и числовыми признаками
- Устойчивость к выбросам

**Слабые стороны:**
- Склонность к переобучению
- Нестабильность (малые изменения данных могут изменить дерево)
- Смещение к признакам с большим числом значений

**Типичные ошибки:**
- Отсутствие ограничения глубины дерева → переобучение
- Неправильный выбор метрики разбиения для задачи
- Игнорирование обработки пропущенных значений
- Отсутствие обрезки дерева (pruning)

## Применение в Machine Learning / AI

1. Классификация медицинских диагнозов: построение дерева решений на основе симптомов пациента (температура, давление, анализы) для предсказания заболевания
2. Кредитный скоринг: использование дерева решений для оценки кредитоспособности заёмщика на основе дохода, истории платежей, возраста
3. Сегментация клиентов: разделение пользователей интернет-магазина на группы по поведенческим признакам для персонализации предложений

## Пример сценария по шагам

**Входные данные:**
Датасет для классификации кредитоспособности:
- Признаки: возраст (25, 35, 45), доход (30000, 50000, 80000), кредитная история (хорошая/плохая)
- Метки: выдать кредит (да/нет)
- Примеры: [(25, 30000, плохая, нет), (35, 50000, хорошая, да), (45, 80000, хорошая, да), ...]

**Шаг 1: Вычисление энтропии исходного набора**
- Энтропия S = -p(да)×log₂(p(да)) - p(нет)×log₂(p(нет))
- Если 50% да, 50% нет: S = -0.5×log₂(0.5) - 0.5×log₂(0.5) = 1.0

**Шаг 2: Выбор признака для разбиения**
- Информационный выигрыш для "возраст": IG(возраст) = S - Σ (|Sᵢ|/|S| × энтропия(Sᵢ))
- Аналогично для "доход" и "кредитная история"
- Выбираем признак с максимальным IG (например, "кредитная история")

**Шаг 3: Разделение данных**
- Узел "кредитная история = хорошая" → подмножество с преимущественно "да"
- Узел "кредитная история = плохая" → подмножество с преимущественно "нет"

**Шаг 4: Рекурсивное построение поддеревьев**
- Для узла "хорошая история": выбираем следующий признак (например, "доход")
- Разделяем на "доход > 40000" и "доход ≤ 40000"
- Продолжаем до достижения критерия остановки

**Шаг 5: Присвоение меток листовым узлам**
- Лист с большинством "да" → метка "выдать кредит"
- Лист с большинством "нет" → метка "не выдавать кредит"

**Итоговый результат:**
Построено дерево решений с правилами: "Если кредитная история хорошая И доход > 40000 → выдать кредит"

## Вопросы для самопроверки

### Базовый уровень

1. Объясните понятия энтропии (entropy) и информационного выигрыша (information gain). Как они используются для выбора признака разбиения?
2. В чём разница между метриками Gini impurity и entropy для построения дерева решений? Когда каждая из них предпочтительнее?

### Средний уровень

1. Опишите критерии остановки при построении дерева решений. Как избежать переобучения? Рассмотрите методы обрезки (pruning).
2. Как обработать категориальные и числовые признаки в дереве решений? Какие проблемы возникают с признаками, имеющими много уникальных значений?

### Продвинутый уровень

1. Докажите, что алгоритм построения дерева решений с максимизацией information gain является жадным алгоритмом. Всегда ли он находит оптимальное дерево?
2. Сравните деревья решений с другими алгоритмами классификации (логистическая регрессия, SVM, случайный лес). Проанализируйте bias-variance trade-off для каждого метода.

## Этическое рассуждение

Применение алгоритмов машинного обучения требует этического подхода:

**Ключевые этические принципы:**
- Справедливость: алгоритм не должен дискриминировать группы пользователей
- Прозрачность: пользователи должны понимать, как принимаются решения
- Приватность: защита персональных данных
- Ответственность: человеческий надзор за критическими решениями
- Безопасность: защита от злоупотреблений и атак
