# Дерево решений

## Определение алгоритма

Decision Tree — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.


## Техническое описание

Decision Tree работает путем последовательной обработки данных согласно определенным правилам и алгоритмам.


## Применение в Machine Learning / AI

1. применение decision tree для решения конкретных задач в области decision
2. использование decision tree в production-системах для tree
3. интеграция decision tree в data pipelines для автоматизации процессов

## Вопросы для самопроверки

### Базовый уровень

1. Объясните понятия энтропии (entropy) и информационного выигрыша (information gain). Как они используются для выбора признака разбиения?
2. В чём разница между метриками Gini impurity и entropy для построения дерева решений? Когда каждая из них предпочтительнее?

### Средний уровень

1. Опишите критерии остановки при построении дерева решений. Как избежать переобучения? Рассмотрите методы обрезки (pruning).
2. Как обработать категориальные и числовые признаки в дереве решений? Какие проблемы возникают с признаками, имеющими много уникальных значений?

### Продвинутый уровень

1. Докажите, что алгоритм построения дерева решений с максимизацией information gain является жадным алгоритмом. Всегда ли он находит оптимальное дерево?
2. Сравните деревья решений с другими алгоритмами классификации (логистическая регрессия, SVM, случайный лес). Проанализируйте bias-variance trade-off для каждого метода.

## Практические задания

### Уровень 1 — базовый

Реализуйте алгоритм построения дерева решений с использованием метрики
information gain. Обучите дерево на простом датасете (например, классификация ирисов) и визуализируйте
полученное дерево.

### Уровень 2 — прикладной

Создайте полноценную реализацию дерева решений с поддержкой:
- Различных метрик разбиения (entropy, Gini impurity)
- Обработки категориальных и числовых признаков
- Критериев остановки (максимальная глубина, минимальное число образцов в листе)
- Обрезки дерева (pruning) для предотвращения переобучения
Обучите на реальном датасете и сравните с реализацией из scikit-learn.

### Уровень 3 — исследовательский

Проведите исследовательский анализ деревьев решений:
- Сравните деревья решений с логистической регрессией и SVM на нескольких датасетах
- Исследуйте влияние гиперпараметров (max_depth, min_samples_split) на bias-variance trade-off
- Реализуйте ансамбль деревьев (Random Forest) и сравните с одним деревом
- Проанализируйте важность признаков (функциональность importance)
- Измерьте время обучения и предсказания, интерпретируемость моделей
- Сформулируйте рекомендации по выбору алгоритма для различных типов задач

## Этическое рассуждение

Применение алгоритмов машинного обучения требует этического подхода:

**Ключевые этические принципы:**
- Справедливость: алгоритм не должен дискриминировать группы пользователей
- Прозрачность: пользователи должны понимать, как принимаются решения
- Приватность: защита персональных данных
- Ответственность: человеческий надзор за критическими решениями
- Безопасность: защита от злоупотреблений и атак
