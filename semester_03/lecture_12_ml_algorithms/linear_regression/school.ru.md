# Linear Regression

## Простое объяснение

Linear Regression Step-by-Step Execution: Start([Start]) --> Init[Initialize data]

Этот алгоритм работает, систематически обрабатывая данные, чтобы достичь своей цели. Он относится к категории алгоритмов **Machine Learning**.

## Сложность алгоритма

Временная сложность составляет **O(n²d)**, что означает, что время выполнения зависит от размера входных данных. Пространственная сложность — **O(nd)**, что указывает на количество дополнительной памяти.

## Где применяется на практике

Linear Regression обычно используется в:
- Software development frameworks
- System optimization
- Data processing pipelines
- Образовании по информатике и изучении алгоритмов

## Частые ошибки

- Не обрабатываются граничные случаи (пустой ввод, один элемент)
- Непонимание последствий сложности
