Data Cataloging — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.

Data Cataloging работает путем последовательной обработки данных согласно определенным правилам и алгоритмам.


## Применение в Data Engineering / Data Governance

1. создание централизованного каталога всех данных организации
2. обнаружение и индексация данных из различных источников
3. управление метаданными и документацией
4. упрощение поиска и доступа к данным
