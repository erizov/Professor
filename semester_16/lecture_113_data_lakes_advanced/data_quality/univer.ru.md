## Применение в Data Engineering / Data Governance

1. Валидация данных при миграции: проверка 50 миллионов записей клиентов на дубликаты (по email, телефону), неполные поля (обязательные колонки), несоответствие форматов (даты, числа) перед загрузкой в новую систему. Генерация отчёта о качестве с метриками completeness, accuracy, validity.
2. Контроль качества в data lake: автоматическая проверка поступающих файлов (Parquet, CSV) на соответствие схеме (наличие всех колонок, правильные типы), диапазоны значений (возраст 0-150, цена > 0), референсную целостность (foreign keys). Использование Great Expectations или аналогичных фреймворков.
3. Мониторинг качества данных в реальном времени: отслеживание метрик completeness (процент заполненных полей), accuracy (соответствие реальным значениям), consistency (согласованность между источниками) для потоков данных в streaming pipeline (Kafka, Flink). Автоматические алерты при деградации качества.
