# Качество данных

## Простое объяснение

Качество данных — это способ проверять, насколько хороши данные. Алгоритм анализирует данные и находит ошибки, пропуски или несоответствия, чтобы убедиться, что информация правильная.

## Где применяется

- проверка правильности данных в таблицах;
- поиск ошибок в больших файлах;
- валидация информации перед использованием;
- контроль качества данных в системах;

## Пример

Проверяем список учеников в классе:

Исходные данные: ["Иван", "", "Мария", "null", "Пётр"]

Шаг 1: Проверяем каждый элемент
Шаг 2: Находим пустую строку "" → ошибка качества
Шаг 3: Находим "null" → ошибка качества
Шаг 4: Составляем отчёт: найдено 2 проблемы

Алгоритм помог найти и исправить ошибки в данных.

## Практические задания

### Уровень 1 (Лёгкий)

Проверь список имён на пустые значения: ["Иван", "", "Мария", "Пётр", ""]. Найди все ошибки.

### Уровень 2 (Средний)

Проверь большой список данных на несколько типов ошибок: пустые значения, неправильный формат, дубликаты. Составь отчёт о найденных проблемах.

### Уровень 3 (Продвинутый)

Создай систему проверки качества данных с правилами валидации. Добавь автоматическое исправление простых ошибок и генерацию подробных отчётов.
