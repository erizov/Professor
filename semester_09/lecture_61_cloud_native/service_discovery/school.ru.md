# Service Discovery

## Простое объяснение

Service Discovery — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.


## Где применяется

- применение service discovery для решения конкретных задач в области service;
- использование service discovery в production-системах для discovery;
- интеграция service discovery в data pipelines для автоматизации процессов;

## Пример

Конкретный пример работы service discovery:
