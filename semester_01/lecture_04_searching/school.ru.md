# Lecture 04 Searching

## Простое объяснение

Лекция 04 Searching — searching algorithms - demonstration. this лекция covers various searching algorithms including linear поиск, binary поиск, and interpolation поиск.

## Где применяется

- поиск ученика в списке класса;
- поиск нужного файла в папке;
- поиск слова в текстовом документе;
- поиск контакта в списке телефонных номеров;
