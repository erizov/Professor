# Линейный поиск

## Простое объяснение

Линейный поиск просматривает элементы списка один за другим, сравнивая каждый с искомым значением, пока не найдёт нужный элемент.

## Пример

Рассмотрим пример работы линейный поиск:

1. Подготовка: получаем входные данные
2. Обработка: применяем алгоритм
3. Результат: получаем ответ

Алгоритм работает последовательно, выполняя необходимые операции.

## Практические задания

### Уровень 1 (Лёгкий)

Найди слово "яблоко" в списке фруктов: ["банан", "яблоко", "апельсин", "груша"].

### Уровень 2 (Средний)

Определи, сколько шагов сделает алгоритм при поиске числа 18 в списке из 20 элементов. Найди все вхождения числа 5 в списке: [1, 5, 3, 5, 7, 5, 9, 2, 5, 4].

### Уровень 3 (Продвинутый)

Напиши простой алгоритм поиска на любом языке программирования, который выводит номер найденного элемента и количество выполненных сравнений. Реализуй поиск для упорядоченного и неупорядоченного списка.
