# Сортировка слиянием

## Простое объяснение

Сортировка слиянием упорядочивает элементы списка по возрастанию или убыванию, используя специальную стратегию сравнения и перестановки элементов.

## Где применяется

- Database query optimization;
- Operating system process scheduling;
- Database query optimization;
- Operating system process scheduling;

## Пример

Рассмотрим пример работы сортировка слиянием:

1. Подготовка: получаем входные данные
2. Обработка: применяем алгоритм
3. Результат: получаем ответ

Алгоритм работает последовательно, выполняя необходимые операции.

## Вопросы для самопроверки

### Базовые

1. Что делает алгоритм сортировки?
2. В каких случаях нужна сортировка?
3. Сколько элементов можно отсортировать этим способом?

### Средние

4. Как работает алгоритм, если элементы уже отсортированы?
5. Почему некоторые алгоритмы сортировки быстрее других?
6. Сколько сравнений нужно для сортировки n элементов?

### Сложные

7. Что изменится, если список очень большой?
8. Как оценить эффективность алгоритма?
9. Можно ли отсортировать данные за один проход?

## Практические задания

### Уровень 1 (Лёгкий)

Отсортируй список фруктов по алфавиту: ["яблоко", "банан", "апельсин", "груша"].

### Уровень 2 (Средний)

Определи, сколько шагов сделает алгоритм при сортировке списка из 10 элементов. Отсортируй список чисел: [64, 34, 25, 12, 22, 11, 90, 5, 77, 1].

### Уровень 3 (Продвинутый)

Напиши простую программу сортировки на любом языке программирования, которая выводит каждый шаг процесса сортировки. Сравни время работы с разными размерами списков.
