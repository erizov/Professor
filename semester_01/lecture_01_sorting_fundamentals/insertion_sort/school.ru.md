**Алгоритм "Insertion Sort"**

**Принцип работы:**
Алгоритм "Insertion Sort" работает путем поочередного вставления каждого элемента на свое место в отсортированную часть массива. На каждом шаге мы берем элемент из неотсортированной части и сравниваем его с элементами в отсортированной части, чтобы найти его правильное место.

**Сложность алгоритма:**
O(n^2) - квадратичная сложность.

**Применение на практике:**
Алгоритм "Insertion Sort" применяется в ситуациях, когда нужно отсортировать небольшой массив или когда массив частично отсортирован.

**Сравнение с другими алгоритмами:**
Можно сравнить с алгоритмами сортировки пузырьком и выбором. "Insertion Sort" может быть эффективнее на небольших массивах.

**Минимальный пример кода:**
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```

**Частые ошибки:**
- Неправильное понимание условия внутреннего цикла.
- Необходимость внимательно следить за индексами.
