# Пузырьковая сортировка

**Алгоритм:** Bubble Sort  
**Дисциплина:** Computer Science

## Определение алгоритма

Пузырьковая сортировка — это алгоритм упорядочивания элементов массива или 
списка по определённому критерию (возрастание, убывание, пользовательский компаратор). Алгоритм 
переставляет элементы, сравнивая их значения и меняя местами при необходимости.

## Техническое описание

### Что делает алгоритм

Пузырьковая сортировка — это простой алгоритм сортировки, который многократно 
проходит по списку, сравнивает соседние элементы и меняет их местами, если они находятся в 
неправильном порядке. Название происходит от того, что более лёгкие элементы "всплывают" наверх, 
как пузырьки в воде.

**Основные этапы:**
1. Сравнение первого элемента со вторым, если первый больше — обмен местами
2. Переход к следующей паре элементов
3. Повторение для всех пар до конца списка (один проход)
4. Повторение проходов до тех пор, пока не будет выполнено ни одного обмена

**Ключевые структуры данных:**
- Одномерный массив для хранения элементов
- Временная переменная для обмена (swap)

**Временная сложность:**
- В худшем случае: O(n²) — когда массив отсортирован в обратном порядке
- В лучшем случае: O(n) — когда массив уже отсортирован (с оптимизацией)
- В среднем случае: O(n²)

**Пространственная сложность:** O(1) — сортировка in-place

**Сильные стороны:**
- Простота реализации
- Стабильность (сохраняет порядок равных элементов)
- In-place сортировка (не требует дополнительной памяти)
- Адаптивность (быстро работает на почти отсортированных данных)

**Слабые стороны:**
- Квадратичная временная сложность
- Неэффективен для больших массивов
- Много избыточных сравнений

**Типичные ошибки:**
- Выход за границы массива при сравнении соседних элементов
- Неправильный подсчёт количества проходов (нужно n-1 проходов)
- Отсутствие оптимизации (продолжение после того, как массив уже отсортирован)
- Неправильная реализация обмена элементов (без временной переменной)

## Применение в Computer Science

1. Образовательные цели: демонстрация базового алгоритма сортировки для студентов (малые массивы до 100 элементов)
2. Сортировка почти отсортированных данных: эффективная обработка списков, где большинство элементов уже на своих местах
3. Встроенные системы: сортировка небольших массивов в устройствах с ограниченными ресурсами, где простота важнее скорости

## Пример сценария по шагам

**Входные данные:**
Массив оценок студентов: [5, 2, 4, 1, 3]
Цель: отсортировать по возрастанию

**Шаг 1: Проход 1 (i = 0)**
- Сравниваем arr[0]=5 и arr[1]=2 → 5 > 2, меняем → [2, 5, 4, 1, 3]
- Сравниваем arr[1]=5 и arr[2]=4 → 5 > 4, меняем → [2, 4, 5, 1, 3]
- Сравниваем arr[2]=5 и arr[3]=1 → 5 > 1, меняем → [2, 4, 1, 5, 3]
- Сравниваем arr[3]=5 и arr[4]=3 → 5 > 3, меняем → [2, 4, 1, 3, 5]
- После прохода 1: [2, 4, 1, 3, 5] (максимальный элемент "всплыл" в конец)

**Шаг 2: Проход 2 (i = 1)**
- Сравниваем arr[0]=2 и arr[1]=4 → 2 < 4, не меняем → [2, 4, 1, 3, 5]
- Сравниваем arr[1]=4 и arr[2]=1 → 4 > 1, меняем → [2, 1, 4, 3, 5]
- Сравниваем arr[2]=4 и arr[3]=3 → 4 > 3, меняем → [2, 1, 3, 4, 5]
- После прохода 2: [2, 1, 3, 4, 5]

**Шаг 3: Проход 3 (i = 2)**
- Сравниваем arr[0]=2 и arr[1]=1 → 2 > 1, меняем → [1, 2, 3, 4, 5]
- Сравниваем arr[1]=2 и arr[2]=3 → 2 < 3, не меняем → [1, 2, 3, 4, 5]
- После прохода 3: [1, 2, 3, 4, 5]

**Шаг 4: Проверка завершения**
Проход 4: нет обменов → массив отсортирован, алгоритм завершён

**Итоговый результат:**
Отсортированный массив: [1, 2, 3, 4, 5]
Количество сравнений: 10
Количество обменов: 7

### Базовый уровень

1. Докажите, что пузырьковая сортировка всегда завершается за конечное число шагов. Каково максимальное количество проходов для массива из n элементов?
2. Почему пузырьковая сортировка имеет временную сложность O(n²) в худшем случае? Подсчитайте точное количество сравнений.

### Средний уровень

3. Как оптимизировать пузырьковую сортировку, чтобы она завершалась раньше, если массив уже отсортирован? Какова сложность оптимизированной версии в лучшем случае?
4. Сравните пузырьковую сортировку с сортировкой вставками. В каких случаях каждая из них предпочтительнее? Приведите примеры.

### Продвинутый уровень

5. Докажите стабильность пузырьковой сортировки. Может ли алгоритм изменить относительный порядок равных элементов?
6. Проанализируйте адаптивность пузырьковой сортировки. Как количество инверсий в массиве влияет на производительность алгоритма? Выведите формулу.
