## Пример сценария по шагам

**Входные данные:**
Массив оценок студентов: [5, 2, 4, 1, 3]
Цель: отсортировать по возрастанию

**Шаг 1: Проход 1 (i = 0)**
- Сравниваем arr[0]=5 и arr[1]=2 → 5 > 2, меняем → [2, 5, 4, 1, 3]
- Сравниваем arr[1]=5 и arr[2]=4 → 5 > 4, меняем → [2, 4, 5, 1, 3]
- Сравниваем arr[2]=5 и arr[3]=1 → 5 > 1, меняем → [2, 4, 1, 5, 3]
- Сравниваем arr[3]=5 и arr[4]=3 → 5 > 3, меняем → [2, 4, 1, 3, 5]
- После прохода 1: [2, 4, 1, 3, 5] (максимальный элемент "всплыл" в конец)

**Шаг 2: Проход 2 (i = 1)**
- Сравниваем arr[0]=2 и arr[1]=4 → 2 < 4, не меняем → [2, 4, 1, 3, 5]
- Сравниваем arr[1]=4 и arr[2]=1 → 4 > 1, меняем → [2, 1, 4, 3, 5]
- Сравниваем arr[2]=4 и arr[3]=3 → 4 > 3, меняем → [2, 1, 3, 4, 5]
- После прохода 2: [2, 1, 3, 4, 5]

**Шаг 3: Проход 3 (i = 2)**
- Сравниваем arr[0]=2 и arr[1]=1 → 2 > 1, меняем → [1, 2, 3, 4, 5]
- Сравниваем arr[1]=2 и arr[2]=3 → 2 < 3, не меняем → [1, 2, 3, 4, 5]
- После прохода 3: [1, 2, 3, 4, 5]

**Шаг 4: Проверка завершения**
Проход 4: нет обменов → массив отсортирован, алгоритм завершён

**Итоговый результат:**
Отсортированный массив: [1, 2, 3, 4, 5]
Количество сравнений: 10
Количество обменов: 7

### Базовый уровень

1. Докажите, что пузырьковая сортировка всегда завершается за конечное число шагов. Каково максимальное количество проходов для массива из n элементов?
2. Почему пузырьковая сортировка имеет временную сложность O(n²) в худшем случае? Подсчитайте точное количество сравнений.

### Средний уровень

1. Как оптимизировать пузырьковую сортировку, чтобы она завершалась раньше, если массив уже отсортирован? Какова сложность оптимизированной версии в лучшем случае?
2. Сравните пузырьковую сортировку с сортировкой вставками. В каких случаях каждая из них предпочтительнее? Приведите примеры.

### Продвинутый уровень

1. Докажите стабильность пузырьковой сортировки. Может ли алгоритм изменить относительный порядок равных элементов?
2. Проанализируйте адаптивность пузырьковой сортировки. Как количество инверсий в массиве влияет на производительность алгоритма? Выведите формулу.
