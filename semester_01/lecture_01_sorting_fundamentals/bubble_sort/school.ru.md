# Пузырьковая сортировка

## Простое объяснение

Bubble Sort — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.


## Где применяется

- применение bubble sort для решения конкретных задач в области bubble;
- использование bubble sort в production-системах для sort;
- интеграция bubble sort в data pipelines для автоматизации процессов;

## Пример

Конкретный пример работы bubble sort:

1. Подготовка данных: входные данные для bubble sort (конкретный формат и структура)
2. Применение алгоритма: последовательность шагов bubble sort для обработки данных
3. Получение результата: конкретный результат работы алгоритма с интерпретацией

## Практические задания

### Уровень 1 (Лёгкий)

Отсортируй список фруктов по алфавиту: ["яблоко", "банан", "апельсин", "груша"].
Выведи каждый шаг сортировки.

### Уровень 2 (Средний)

Отсортируй список из 10 чисел: [64, 34, 25, 12, 22, 11, 90, 5, 77, 1].
Подсчитай количество сравнений и перестановок.

### Уровень 3 (Продвинутый)

Напиши программу пузырьковой сортировки, которая выводит каждый шаг процесса.
Сравни время работы с разными размерами списков (10, 100, 1000 элементов) и
визуализируй результаты на графике.
