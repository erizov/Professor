## Вопросы для самопроверки

### Базовый уровень

1. Докажите корректность бинарного поиска: алгоритм всегда находит элемент, если он присутствует в отсортированном массиве.
2. Почему бинарный поиск требует отсортированного массива? Что произойдёт, если применить алгоритм к неотсортированным данным?

### Средний уровень

1. Как найти не только наличие элемента, но и первое/последнее вхождение в отсортированном массиве с дубликатами? Модифицируйте алгоритм бинарного поиска.
2. Сравните итеративную и рекурсивную реализации бинарного поиска. Какая из них предпочтительнее с точки зрения производительности и использования памяти?

### Продвинутый уровень

1. Докажите, что бинарный поиск оптимален для задачи поиска в отсортированном массиве. Используйте модель дерева решений для доказательства нижней границы Ω(log n).
2. Как адаптировать бинарный поиск для работы с очень большими массивами, которые не помещаются в память? Рассмотрите внешнюю сортировку и бинарный поиск на диске.

## Практические задания

### Уровень 1 — базовый

Реализуйте бинарный поиск в отсортированном массиве. Создайте как
итеративную, так и рекурсивную версии. Протестируйте на массивах разного размера и сравните
количество сравнений с теоретической оценкой O(log n).

### Уровень 2 — прикладной

Расширьте бинарный поиск для работы с:
- Поиском первого вхождения элемента (lower_bound)
- Поиском последнего вхождения элемента (upper_bound)
- Поиском диапазона вхождений элемента
Протестируйте на массивах с дубликатами и сравните эффективность с линейным поиском.

### Уровень 3 — исследовательский

Проведите исследование бинарного поиска в различных контекстах:
- Сравните бинарный поиск с хеш-таблицами для задачи поиска
- Реализуйте бинарный поиск для работы с внешней памятью (большие файлы)
- Адаптируйте алгоритм для поиска в многомерных отсортированных массивах
- Измерьте производительность на реальных данных (например, поиск в отсортированном списке IP-адресов)
- Сформулируйте рекомендации по выбору структуры данных для поиска
