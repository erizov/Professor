### Short Description

NoSQL databases that store data as key-value pairs, providing simple and fast access. Addresses caching, session storage, and high-performance lookups. Example: Storing user sessions as key (session_id) and value (user_data JSON) for fast retrieval. Operates by maintaining hash tables or similar structures that map keys directly to values, enabling O(1) lookup time.
