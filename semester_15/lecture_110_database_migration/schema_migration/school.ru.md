# Schema Migration

## Простое объяснение

Schema Migration — это алгоритм, используемый для решения конкретных задач в области компьютерных наук.


## Где применяется

- применение schema migration для решения конкретных задач в области schema;
- использование schema migration в production-системах для migration;
- интеграция schema migration в data pipelines для автоматизации процессов;
